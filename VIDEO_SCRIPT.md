# Airdrop Scam Shield — Demo Video Script (max 3 minutes)

Target: Devpost submission for #BuildHybridAI 2026. Language: English (narration + on-screen text). Record the deployed demo in Chrome on desktop. Total target: ~2 minutes 30 seconds.

## 0:00–0:15 — The problem

On screen: a Telegram airdrop message promising guaranteed daily returns.

Narration: "Every day, crypto users get airdrop messages like this one. Some are real. Many are scams that drain wallets. Most people have no fast way to tell the difference."

## 0:15–0:45 — Paste and instant pre-check

On screen: paste the scam message into Airdrop Scam Shield, click Scan. Local red flags appear instantly.

Narration: "Paste the message, link, or token contract. The app first runs an instant local check for classic scam patterns: seed phrase requests, send-to-get doubling, guaranteed returns, fake verification. No network needed, no data leaves the device."

## 0:45–1:30 — On-device triage (the hybrid story)

On screen: the quick triage result appears with a large ON_DEVICE badge. Verdict DANGER, risk score, flags with explanations.

Narration: "Then Firebase AI Logic runs a quick triage on-device with Gemini Nano. It is free, private, and works offline. See the badge: this answer came from the device itself. If the device cannot run the model, the same call falls back to the cloud automatically."

## 1:30–2:00 — Cloud fallback + deep analysis

On screen: click Deep analysis on a token contract. On-chain facts card appears (contract verified, pair and liquidity from DexScreener), then the cloud verdict with an IN_CLOUD badge.

Narration: "For a deeper look, Deep analysis checks on-chain facts first — is the contract verified, does a trading pair with real liquidity exist — and then asks the cloud model. Facts first, AI second, so the verdict can be checked."

## 2:00–2:30 — Wrap up

On screen: scan history panel, then the Firebase AI Logic architecture (on-device → cloud fallback).

Narration: "Airdrop Scam Shield: fast local triage, on-device AI when available, cloud AI when needed. Built with Firebase AI Logic hybrid inference. Try the live demo at the link below."

## Recording notes

- Record at 1080p, Chrome window only, hide bookmarks bar and personal tabs.
- Use the built-in example buttons for the scam message and the token contract so the demo is repeatable.
- Do not show any API key, debug token, or Firebase console secret on screen.
- Keep the final video under 3 minutes; export as MP4 and upload to YouTube as Public or Unlisted.
